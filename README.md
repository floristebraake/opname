# Opname-app (T Bouw · Strak · Gevelstucspecialist)

Web-app voor opnames op locatie: adres (BAG), aanvraag uit agent 1, maten per ruimte,
foto's, memo, vaste tarieven. Verstuurt het dossier via Make naar de adresmap in AA - BV.

- Geen sleutels of klantgegevens in deze repository. De verbinding wordt eenmalig op de
  telefoon ingesteld via een installatielink.
- Bron en documentatie: AA - BV/Claude_Werkmap_TBouw_Strak/tools/opname-app.
